# Проверка в браузере

Только если Кирилл явно попросил посмотреть. Хук покажет карточку — без его «Allow» браузер не откроется.

## Шаги

1. Локально: `python3 -m http.server 8765` в корне проекта, если порт свободен. Иначе использовать уже запущенный.
2. Открыть `http://127.0.0.1:8765/`.
3. Прогнать изменённый сценарий (карточка, кнопка, модалка), не все вкладки подряд.
4. Скрин — только если правили вёрстку и без него не видно. Не Computer Use.
5. В конце unlock браузера.

Ответ короткий: что проверил и что увидел.
