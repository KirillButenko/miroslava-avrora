# Дневник Мирославы и Авроры

Семейный сайт для двух дочерей: кормления, вес, этапы месяца и графики.

Данные хранятся в браузере посетителя (`localStorage`). На GitHub они не уходят — так можно открыть дневник с телефона и сразу записывать, без регистрации.

## Сайт

Сайт: https://kirillbutenko.github.io/miroslava-avrora/

Репозиторий: https://github.com/KirillButenko/miroslava-avrora

## Как пользоваться

1. Укажите дату рождения.
2. На вкладке **Сегодня** быстро запишите кормление.
3. В **Кормлениях** и **Весе** ведите журнал по каждой девочке.
4. В **Этапах** отметьте, что уже получается.
5. **Графики** строятся из сохранённых записей.
6. **Скачать данные** / **Загрузить данные** — чтобы перенести дневник на другой телефон.

## Запуск у себя

Откройте `index.html` или из папки проекта:

```bash
python3 -m http.server 8765
```

Затем зайдите на `http://127.0.0.1:8765/`.
